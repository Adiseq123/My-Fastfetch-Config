Estetyczna, spersonalizowana konfiguracja **Fastfetch** przygotowana z myślą o przejrzystym wyświetlaniu najważniejszych informacji o systemie bezpośrednio w terminalu.

Konfiguracja wykorzystuje własny układ oparty na ramce ASCII, kolorach oraz podziale informacji na kilka czytelnych sekcji.

## ✨ Funkcje

- 🖼️ **Logo Fastfetch** — własne ustawienie odstępów wokół logo.
- 👤 **Informacje o użytkowniku i hoście** — wyświetlanie nazwy użytkownika oraz hostname.
- 🖥️ **Informacje o systemie** — system operacyjny, kernel, czas działania oraz liczba zainstalowanych pakietów.
- 🎨 **Środowisko graficzne** — DE, WM, motyw, rozdzielczość monitora, shell oraz używana czcionka terminala.
- ⚙️ **Informacje o podzespołach** — procesor, karta graficzna, pamięć RAM oraz wykorzystanie dysku.
- 🌈 **Paleta kolorów** — prezentacja aktualnych kolorów terminala w formie symboli.
- 📦 **Czytelny układ** — wszystkie informacje zostały podzielone na sekcje i umieszczone w jednej spójnej ramce.
- 🇵🇱 **Polskie opisy** — wszystkie etykiety konfiguracji są przygotowane w języku polskim.

## 📋 Wyświetlane informacje

### 🖥️ System
- System operacyjny
- Kernel
- Czas działania
- Liczba pakietów

### 🎨 Środowisko
- Środowisko graficzne
- Menadżer okien
- Motyw
- Rozdzielczość monitora
- Powłoka
- Czcionka terminala

### ⚙️ Podzespoły
- Procesor
- Karta graficzna
- Pamięć RAM
- Dysk `/`

## 🚀 Instalacja

Wymagany jest zainstalowany **Fastfetch**.

Następnie umieść konfigurację w katalogu konfiguracyjnym Fastfetch i uruchom:

```bash
fastfetch
```

Możesz również wskazać konfigurację bezpośrednio podczas uruchamiania Fastfetch, zależnie od używanej wersji programu.
